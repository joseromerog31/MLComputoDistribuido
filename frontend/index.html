PRUEBAS DISTRIBUIDAS

Tolerancia a fallos

Desde la terminal de Kali detén un worker, espera el siguiente health check, ejecuta otro lote y observa si se utilizan menos workers.

docker compose stop worker-2
# Esperar > 5 segundos
# Ejecutar otro lote desde el dashboard

docker compose start worker-2

Los estados por worker no pueden consultarse en vivo hasta que añadamos GET /workers al coordinador.
